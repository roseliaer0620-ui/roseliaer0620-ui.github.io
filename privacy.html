Privacy policy for rclone-fc

Effective date: 2026-11-01

rclone-fc is a personal, single-user Google Drive client built on rclone. This policy explains how the app handles Google user data.

Google Drive access

The app requests Google Drive access with the scope https://www.googleapis.com/auth/drive only to upload, list, and manage the owner's own files in their own Drive.

How data is used

The data is used only to perform the user-requested file operations.

How tokens are stored

OAuth tokens are stored only locally on the owner's own machine in the rclone config file.

Sharing, analytics, and ads

No data is sold, shared with, or transferred to any third party. The app does not use analytics or ads.

Google API Services User Data Policy

rclone-fc's use of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke this app's access to your Google account at any time at https://myaccount.google.com/permissions.
